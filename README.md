# Syfernetics Home

Professional portfolio and service website for Syfernetics.

This rebuild uses the final Syfernetics palette:

- Primary Background: `#0F172A`
- Secondary Background: `#111827`
- Card / Panel: `#1F2937`
- Primary Text: `#F8FAFC`
- Muted Text: `#94A3B8`
- Accent: `#14B8A6`
- Accent Hover: `#0D9488`

## Positioning

Syfernetics focuses on practical technology solutions:

- Full-stack web development
- Workflow and operations tools
- Business dashboards
- Security-minded software implementation
- Practical digital solutions for small businesses, employers, and teams

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Pages

- Home
- Projects
- About
- Contact
- Blog placeholder
- Project detail placeholder

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Rebuild Notes

This version was redesigned to match a professional SaaS/product-design direction instead of a heavy cyber/futuristic theme. It keeps a dark technical identity while making the brand feel more credible for employers and clients.
